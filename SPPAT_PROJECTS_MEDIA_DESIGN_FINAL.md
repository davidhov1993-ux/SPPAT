## 0. FINAL PRODUCT DECISION

This document is the single production brief for the designer for the **Projecten + real-photo layer** of Sppat.

The approved design system remains **“The Anatomy of Precision.”** This document does **not** authorize a redesign. It adds the project/media system that was previously missing.

Non-negotiable rules:

1. **Real project photography and illustrative imagery are different asset classes.**
2. No AI/reference image may be presented as a Sppat project.
3. No location, material, brand, installation method, project duration, technical system or scope may be inferred from an image and published as fact.
4. Project photography is evidence. Preserve evidence; do not beautify it into a different project.
5. The Projecten page will **not use filters in V1**. The source portfolio is not yet large enough for filters to improve UX.
6. The page must work with unequal project asset counts. Some projects have 5 images, others 2.
7. Real photography should be visually elevated by layout, cropping, typography and sequencing — not by fabricating content.
8. Existing page families and the approved Sppat visual language remain unchanged.

## 3. PROJECTEN PAGE DESIGN SPECIFICATION

### `/projecten/` — listing

**Purpose:** trust/proof, not SEO keyword inventory.

**Desktop**
- Intro/H1 block remains text-led.
- First project is a larger feature entry.
- Remaining projects use an editorial grid, not six identical cards.
- Primary listing-image ratio: **4:3**.
- Allow one controlled **portrait 4:5 feature** to break mechanical repetition.
- Project titles/locations must not be invented. If factual title data is unavailable, use a neutral descriptive label approved by PM before publishing.
- Do not place decorative badges/pills on photos.

**Tablet**
- Two-column grid only where each image still has sufficient visual width.
- At ~834px, never compress imagery into narrow 12-column remnants; use 1–2 deliberate tracks.
- Text must not be squeezed beside portrait media.

**Mobile**
- One column.
- Listing media ratio: **4:5**.
- Image first only on project cards; title/metadata follows.
- No horizontally scrolling portfolio carousel.

Template must support:
- **Tier A:** 4–6 images.

Sequence:
1. Breadcrumb.
2. Project title + verified facts.
3. Hero media.
4. Short verified scope statement.
5. Visual proof sequence.
6. Relevant service links (2–4 maximum).
7. Final CTA.

Do not create empty “technical specifications” tables when facts are missing.

## 5. PHOTO EDITING RULES

### Allowed
- Straighten.
- Perspective correction.
- Crop.
- White-balance correction.
- Exposure/highlight/shadow correction.
- Moderate contrast and local clarity.
- Lens correction.
- Mild noise reduction.
- Mild sharpening.
- Crop out phone UI/status bars where present.
- Crop out incidental bags/tools when this can be done without changing the architectural evidence.

### Forbidden for real project assets
- AI replacement of tiles, grout, furniture, sanitary ware, walls, floors, doors, lighting or architectural geometry.
- Generating a “clean” missing part of the room.
- Changing material color/pattern.
- Removing defects in workmanship.
- Adding LED, niches, drains, fixtures or decor.
- Compositing two different projects.
- Replacing sky/window views to imply another location.
- Using generative expansion as evidence of the original project.

### Recommended tonal direction
Real photos should be normalized toward the Sppat site:
- neutral white balance;
- controlled highlights;
- blacks retained, not crushed;
- no HDR look;
- no heavy warm luxury filter;
- preserve material texture and grout/joint visibility.
